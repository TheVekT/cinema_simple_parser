## Cinema Simple Parser (Planeta Kino)

Цей проект є прикладом лабораторної роботи, виконаної у 2024 році. Основна функціональність полягає у парсингу розкладу сеансів кінотеатру **Планета Кіно (Львів-Leoland)** з офіційного сайту.

> **Увага:** Проект може бути непрацездатним на даний момент, оскільки структура сайту [planetakino.ua](https://planetakino.ua/lviv-leo/showtimes/#month) могла змінитись. Цей репозиторій збережено для архівних цілей.

## Основні характеристики
- **Парсинг даних:** Використовує Selenium та BeautifulSoup4 для витягування інформації про фільми та сеанси.
- **Графічний інтерфейс:** Побудований на PyQt6.
- **Асинхронність:** Використання `qasync` для запобігання блокуванню UI під час роботи парсера.

## Стек технологій
- Python 3.12.x
- PyQt6
- Selenium (потребує ChromeDriver)
- BeautifulSoup4
- qasync

## Як запустити (для історії)
1. Встановити залежності:
   ```bash
   pip install PyQt6 selenium beautifulsoup4 qasync
   ```
2. Переконатися, що шлях до `chromedriver` у файлі `cinema_parser/parser/main_parser.py` вказано правильно (або він знаходиться у системному PATH).
3. Запустити головний файл:
   ```bash
   python main.py
   ```
